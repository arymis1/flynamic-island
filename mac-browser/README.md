# FLYnamic Island — Browser music

YouTube Music in Google Chrome, with CPU/RAM stats and two-finger page swipe. Version 1.0, build 1. Apple silicon. Requires Chrome Automation consent and Allow JavaScript from Apple Events.

Build with `./build.sh` on macOS with Xcode command-line tools. The result stays in this folder and is not installed or launched automatically. See the [root README](../README.md) for downloads, permissions and packaging.
