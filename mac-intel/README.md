# Flynamic Island — Intel Mac

Apple Music / Spotify desktop, with CPU/RAM stats and two-finger page swipe. Version 1.3, build 26. Intel x86_64, macOS 14+. Based on the original Music + System Stats source. Physical Intel testing remains pending.

Build with `./build.sh` on macOS with Xcode command-line tools. The result stays in this folder and is not installed or launched automatically. See [setup](../docs/downloads.md).
