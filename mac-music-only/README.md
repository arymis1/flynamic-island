# Flynamic Island — Music Only

Apple Music and Spotify desktop on Apple silicon. Version 1.2, build 12.

The compact bars animate when a song plays and settle into dots when paused. They use playback state and require no system audio capture.

Build with `./build.sh` on macOS with Xcode command-line tools. The result stays in this folder and is not installed or launched automatically. See [setup](../docs/downloads.md).
