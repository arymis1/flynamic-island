# Flynamic Island — Music + System Stats

Apple Music and Spotify desktop, with CPU/RAM stats and two-finger page swipe. Version 1.3, build 29. Apple silicon.

The compact bars animate when a song plays and settle into dots when paused. They use playback state and require no system audio capture. The expanded panel uses Liquid Glass on macOS 26 and later.

Build with `./build.sh` on macOS with Xcode command-line tools. The result stays in this folder and is not installed or launched automatically. See the [root README](../README.md) for downloads, permissions and packaging.
